# Pemrograman_AnnisaSaniyatuDzakiyyah_Zircon_TLS26
Repositori ini berisi dua problem: The Last Astronaut (pseudocode) dan Alien-In-The-Middle (flowchart), yang keduanya juga disajikan dalam C++. Problem1 menyeleksi astronot dengan bilangan tertentu hingga tersisa satu. Problem2 mengolah pesan rahasia dengan mempertahankan huruf pertama dan menggeser huruf berikutnya sesuai nilai huruf sebelumnya.
